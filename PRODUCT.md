# Directivas de Producto - ReleaseHub

## Visión
Aplicación **stateless** para visualizar pipelines y gestionar releases sin clonación local.

## Decisiones Clave
- **Sin Clones**: Solo API de GitHub para proteger cambios locales del usuario.
- **Marca**: Amarillo #F59E0B.
- **Monitoreo Unificado**: Arquitectura única para todos los proveedores de CI/CD.
- **Salud Omnipresente**: Estado de servicios accesible directamente desde el dashboard.
- **Asistencia Ubicua**: Asistente AI local multimodal (Gemini Nano) para soporte contextual.
