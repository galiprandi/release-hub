# Directivas de Producto - ReleaseHub

## Visión
Aplicación **cache-first** para visualizar pipelines y gestionar releases sin clonación local.

## Decisiones Clave
- **Sin Clones**: Solo API de GitHub. Ver `AGENTS.md` §3.
- **Monitoreo Unificado**: Arquitectura única para todos los proveedores de CI/CD.
- **Salud Omnipresente**: Estado de servicios accesible desde el dashboard.
- **Asistencia Ubicua**: Asistente AI local multimodal. Ver `WEBMCP.md`.
